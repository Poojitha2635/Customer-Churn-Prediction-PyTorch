#  Customer Churn Prediction using PyTorch

## Project Overview
This project develops a Customer Churn Prediction model using PyTorch. It demonstrates the complete machine learning workflow, including data preprocessing, feature engineering, model building, training, evaluation, and prediction. The goal is to identify customers who are likely to churn so businesses can improve customer retention strategies.

--

## Objectives
- Clean and preprocess customer data.
- Build a deep learning model using PyTorch.
- Predict customer churn.
- Evaluate model performance.
- Support data-driven customer retention decisions.

## Project Workflow

### Step 1: Data Collection
- Imported the customer churn dataset into Google Colab.

### Step 2: Data Preprocessing
- Removed duplicate records.
- Handled missing values.
- Encoded categorical variables.
- Scaled numerical features.
- Split data into training and testing sets.

### Step 3: Model Development
- Built a neural network using PyTorch.
- Defined the loss function.
- Selected the optimizer.
- Trained the model over multiple epochs.

### Step 4: Model Evaluation
- Predicted customer churn.
- Evaluated model performance using:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
  - Confusion Matrix

### Step 5: Data Visualization
- Training Loss Curve
- Accuracy Curve
- Confusion Matrix
- Feature Distribution
